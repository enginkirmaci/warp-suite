warp-suite for Windows
======================

This bundle contains the four warp-suite desktop apps:

  apps\warp-station\warp-station.exe
  apps\warp-agent\warp-agent.exe
  apps\warp-notes\warp-notes.exe
  apps\warp-snapit\warp-snapit.exe

Install
-------

Double-click install.cmd. It installs under

  %LOCALAPPDATA%\Programs\warp-suite

and adds a "warp-suite" folder to the Start Menu with one shortcut per app.
No administrator rights are needed.

Portable use
------------

You can also run the .exe files directly from the extracted folder without
installing anything. Keep each app in its own folder; Warp SnapIt expects its
settings\snapit folder next to warp-snapit.exe.

Uninstall
---------

Double-click uninstall.cmd. It removes exactly the files the installer wrote.

Requirements
------------

Windows 10 or 11, x64.
