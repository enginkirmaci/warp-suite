The shell

The list decides what you are looking at, the detail shows it. Rail 76 px, list 432 px by default and resizable from 320 to 560, title bar 46 px, tab strip 40 px. The detail takes the rest. A repository opened in a tab is the same detail pane at full width.

Colour

Lifted surfaces, separated by value. The darkest step is a recessed well, not the window. Contrast is measured live against the base surface.

Tiles (Agent)

The Agent detail pane is a grid of tiles, not a page. Columns are the rounded-up square root of the open chats and the gutter is 12, so one tile fills the pane and three leave one cell empty. A tile is the same card as everywhere else: base on the detail pane, a 44 head on a hairline, the transcript, then the composer as the card foot. The state word carries its entity icon and hue: behind while it runs, changes when it waits on a person. Inside a tile, a card (approval, question) is panel so it lifts off the tile, and a plain button is raised. Under 560 wide the locked harness keeps only its icon and the ring drops the percent; under 440 the state word goes unless it needs you.

Menus

Toasts

Bottom right, stacked. Success and info leave on their own. Errors stay longer, have a close button and take the danger border.

Empty states

Say what is true and offer the next step. An empty state never shows a placeholder or lorem text.

Dialog

Discard 17 changes?

This cannot be undone. A dialog is the only overlay in the suite, and it is used for decisions that block.

Motion

Quiet and short. Motion says that something changed or that work is running, it never decorates. Only opacity and transform move, so GPUI can draw all of it.
